# Roomory

Интерактивная 2D-карта хранения вещей. Курсовой проект по фундаментальной информатике, МАИ.

## Запуск

Не нужны Node.js, сборка, API-ключи или установка библиотек.

1. Скачайте репозиторий: **Code → Download ZIP**, распакуйте архив.
2. Откройте `index.html` в современном браузере.

Для разработки предпочтителен локальный HTTP-сервер: откройте терминал в папке проекта и выполните:

```sh
python3 -m http.server 5173
```

Откройте http://localhost:5173. Для остановки нажмите Ctrl+C. В Windows вместо `python3` может потребоваться `py`.

## Что работает в версии 0.2

- Три демонстрационные комнаты: спальня, кабинет и пустая гостиная. Навигация работает на компьютере и телефоне.
- Нажатие на мебель открывает отделения и список вещей с количеством.
- Поиск по части названия без учёта регистра. Например: «ПАСП», «шарф», «зарядка».
- Поиск работает по всем комнатам. Выбор результата открывает нужную комнату и выделяет мебель на плане и вещь в панели; в результате указан полный путь.
- Пустой поиск, отсутствие совпадений, поиск с клавиатуры (`/`, Tab, Enter, Escape).
- Выбранная комната и мебель восстанавливаются после перезагрузки через localStorage.
- Адаптивный интерфейс без внешних шрифтов, аналитики и запросов к сторонним сервисам.

**Это первый демонстрационный этап.** Создавать комнаты, редактировать мебель и вещи пока нельзя. Данные комнат заданы в `app.js`; localStorage сейчас хранит только выбор комнаты и мебели. Постоянное сохранение редактируемого проекта будет реализовано вместе с редактором. Приватный режим и настройки браузера могут ограничивать сохранение. При открытии файла напрямую поведение localStorage зависит от браузера; HTTP-сервер даёт стабильный адрес хранения.

## Структура

- `index.html` — структура экрана.
- `styles.css` — оформление, план, адаптивные размеры.
- `app.js` — демонстрационные данные в метрах, отображение, поиск, выбор и сохранение состояния.
- `docs/project-plan.md` — границы первой версии и критерии готовности.
- `docs/tasks.md` — последовательность разработки.
- `docs/verification.md` — фактические проверки текущего этапа.
