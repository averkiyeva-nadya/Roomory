# Проверка версии 0.1

Проверено при разработке в браузере через локальный HTTP-сервер:

| Проверка | Фактический результат |
| --- | --- |
| Загрузка страницы | План, шесть предметов мебели и содержимое шкафа отображаются. HTTP 200. |
| Поиск `ПАСП` | Найден «Паспорт», путь «Спальня → Комод → Верхний ящик». |
| Выбор результата | Комод выбран на плане; паспорт выделен в панели содержимого. |
| Перезагрузка | Комод остаётся выбранным, панель показывает его содержимое. |
| Несуществующая вещь | Показано сообщение об отсутствии результатов. |
| Очистка поиска | Результаты скрыты, панель содержимого остаётся доступна. |
| Экран 390 × 844 | План и панель располагаются друг под другом. Ширина документа и экрана совпадает — 390 px. Уменьшены подписи узкой мебели после визуальной проверки. |
| Синтаксис JavaScript | `node --check app.js` выполнен успешно. |

Полный проход с клавиатуры, другие браузеры, реальный телефон, недоступный localStorage и пользовательские интервью на этом этапе не проверялись. Редактор и сохранение полного проекта ещё не реализованы.

## Визуальный прототип 0.2

Фактически проверено в браузере:
- Переключение на пустую гостиную: пустой план, объяснение и панель без выбранной мебели.
- Поиск «флеш» из гостиной: найден путь в кабинет, выбор результата открывает кабинет и выделяет рабочий стол и флешку.
- Выбор пустого комода: понятное состояние «Пока ничего не лежит».
- Перезагрузка восстанавливает кабинет и комод.
- Экран 360 × 800: комнаты доступны сверху, панель под планом; ширина документа 360 px совпадает с шириной окна.
- После финальных изменений страница перезагружена, проверены переключение в спальню и отображение на компьютере.
- `node --check app.js` и `git diff --check` проходят.

Новые комнаты — демонстрационные данные, редактор не добавлен. На реальном телефоне проверка ещё не проводилась.

## Редактор 0.3

Проверено в браузере на отдельной созданной тестовой комнате:
- Создание комнаты 3 × 2 м и шкафа 2,5 × 0,6 м.
- Запрет поворота шкафа: после поворота его длина 2,5 м не помещается в 2 м комнаты.
- Уменьшение ширины комнаты до 2 м блокируется; сообщение называет конфликтующий шкаф.
- Переименование в «Мастерская» и увеличение комнаты до 3 × 3 м.
- Успешный поворот: размеры становятся 0,6 × 2,5 м, угол 90°.
- Кнопка вправо меняет координату на 0,1 м.
- Перетаскивание за пределы комнаты ограничивает координаты значениями x=2,4, y=0,5: мебель остаётся внутри 3 × 3 м.
- Перезагрузка восстанавливает комнату, размеры, положение и угол мебели.
- Стрелка влево на клавиатуре меняет x с 2,4 на 2,3 м.
- Пустое название блокируется; переименование и уменьшение мебели до 0,5 × 2 м сохраняется.
- Удаление тестовой мебели через подтверждение показывает пустую комнату.
- Удаление тестовой комнаты через подтверждение возвращает к спальне; стартовые комнаты сохранены.
- Форма параметров комнаты на 360 × 800: поля и действия помещаются, ширина документа 360 px.

Касание на физическом телефоне, сбой localStorage и удаление последней комнаты вручную не проверялись. Пересечения мебели допускаются. Тестовые объекты после проверки удалены через интерфейс.
