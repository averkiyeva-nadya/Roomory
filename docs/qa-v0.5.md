# Roomory 0.5 — пользовательская проверка

Проверка проведена в браузере на отдельном локальном адресе, чтобы не затронуть данные открытого пользовательского проекта. Исходные данные и тестовые копии не включаются в приложение.

## Фактически выполнено

| Сценарий | Наблюдение |
| --- | --- |
| Импорт пустого проекта | После подтверждения комнат нет, создание первой комнаты доступно; действия с отсутствующей комнатой отключены. |
| Пустое название комнаты | Создание блокируется с объяснением. |
| Размеры −2, 0 и 31 м | Значения отклонены, проект не меняется. |
| Слишком длинное название комнаты | Название длиннее 60 символов отклонено; допустимое длинное название сохраняется. |
| Комната 3 × 2 м | Создаётся, видны площадь 6 м² и размеры. |
| Мебель шириной 4 м в комнате шириной 3 м | Создание блокируется. |
| Шкаф 2,5 × 0,6 м | Создаётся в масштабе. |
| Вещь с названием из пробелов | Сохранение блокируется. |
| Дробное количество 1,5 | Сохранение блокируется; целое 2 принимается. |
| Заметка `<b>В синем чехле</b>` | Отображается буквальным текстом, не превращается в HTML. |
| Вещь без отдельной полки | Сохраняется в постоянной группе без полки. |
| Поворот шкафа в комнате 3 × 2 м | Блокируется: длина после поворота не помещается. |
| Перемещение кнопкой вправо | Координата меняется с 0 до 0,1 м. |
| Уменьшение комнаты до ширины 2 м | Изменение блокируется, назван конфликтующий шкаф. |
| Удаление мебели и комнаты с вещами | Оба действия блокируются; содержимое остаётся. |
| Создание нового ящика и перенос вещи | Вещь переходит из группы без полки в созданный ящик; после перезагрузки новое место сохраняется. |
| Экспорт | Браузер скачал JSON созданного проекта. Дополнительно прочитаны файл и проверены размеры комнаты, координата мебели, количество вещи. |
| Некорректный JSON | Импорт отклонён, текущая комната и вещь остались. |
| Копия с мебелью за границами | Импорт отклонён с причиной; текущий проект остался. |
| Отмена корректного импорта | Текущий проект не заменяется. |
| Импорт проверенной копии с двумя комнатами | Предварительный просмотр показывает 2 комнаты, 2 предмета мебели, 2 записи вещей; после подтверждения появляются данные копии. |
| Поиск `КАБ` | По части слова и без учёта регистра найдены две разные вещи из разных комнат, показаны полные пути. |
| Выбор второго результата клавиатурой | Стрелки и Enter открывают нужную комнату, выделяют мебель и запись в панели. |
| Несуществующее название | Показано отсутствие результатов. |
| Восстановление реально скачанного файла | Возвращаются созданная комната, мебель, координаты, вещь, количество и заметка; повторная перезагрузка сохраняет их. |
| Название вещи 80 букв без пробелов и длинная заметка | Данные отображаются с переносами; в узкой области нет горизонтального переполнения. |
| Компьютер | Проверены основной экран, формы, поиск и диалоги импорта. |
| Мобильная компоновка | Проверена в области iframe 360 × 800 CSS px: ширина HTML и scrollWidth равны 360, доступны формы и навигация. Это не физическое мобильное устройство. |

Ранее в 0.3–0.4 отдельно проверены перетаскивание к границам, успешный поворот, переименование и удаление пустых объектов, удаление полки с сохранением вещей, перенос между мебелью и комнатами и удаление отдельных вещей; см. `verification.md`.

## Исправления

- Пустой проект больше не показывает фиктивные 20 м² и размеры несуществующей комнаты.
- Длинные названия переносятся, навигационные подписи ограничены двумя строками; полное название доступно в подсказке и заголовке плана.
- Сообщения о запрете действий и ошибках видны у нижнего края экрана, даже если кнопка находится далеко от начала страницы.
- Ошибка записи localStorage больше не сопровождается утверждением «сохранено»: показано, что изменения доступны только в текущей вкладке и нужен экспорт.
- Повреждённая исходная запись localStorage не перезаписывается автоматически демонстрационными данными; восстановление возможно через проверенный импорт.
- Проверка JSON используется и для загрузки локального проекта, и для резервных копий; создаётся новая копия только разрешённых полей.
- Добавлены предварительный просмотр импорта и обязательное подтверждение замены, а также экспорт текущего проекта прямо из диалога.
- При ошибке записи импортируемой копии в localStorage замена текущего проекта не выполняется.
- Для поиска добавлены счётчик, управление стрелками и прокрутка к самой найденной вещи.

## Автоматические проверки

`node --test tests/data.test.cjs`: 7 тестов проходят. Проверяются обратимое преобразование JSON, совместимость старых мест хранения, отсутствие мутации исходных данных, повторяющиеся идентификаторы на всех уровнях, неверные размеры/координаты/углы/количества/заметки, некорректный JSON и версия, пустой проект, исключение посторонних полей, BOM.

`node --check app.js`, `node --check data.js` и `git diff --check` проходят.

## Ограничения и непроверенное

- Не проверялись физические iPhone/Android, Safari/Firefox и экранная клавиатура телефона. Тест выполнен в доступном встроенном браузере.
- Не имитировались фактическое переполнение квоты, запрет localStorage, обрыв загрузки, повреждение локальной записи браузера. Соответствующие обработчики есть, но эти ветви не считаются пройденными в браузере.
- Одновременное редактирование в нескольких вкладках не синхронизируется: последняя сохранённая версия может заменить изменения другой вкладки. Работать следует в одной вкладке.
- Локальное хранение зависит от браузера и адреса. Копии JSON нужно сохранять самостоятельно; облачной синхронизации и автоматической истории нет.
- Импорт полностью заменяет проект, не объединяет его. Лимит копии — 5 МБ, до 100 комнат, 500 предметов мебели на комнату, 200 мест на предмет и 20000 записей вещей в проекте.
- Мебель может пересекаться, двери/окна декоративные. Проверка границ не является проверкой физической расстановки.
- Удалённые отдельные вещи не попадают в корзину; требуется подтверждение. Восстановление — из заранее сохранённой копии.
